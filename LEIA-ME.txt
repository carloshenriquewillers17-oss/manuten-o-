DMV ENGENHARIA - ATUALIZACAO v12 (BOTAO EXCLUIR OS)

1. Abra o repositorio manuten-o- no GitHub.
2. Entre em Code > Add file > Upload files.
3. Extraia este ZIP e envie os arquivos diretamente para a raiz do repositorio, substituindo os anteriores. Inclua a pasta icons.
4. Clique em Commit changes e aguarde a aba Actions ficar verde.
5. No celular, feche completamente o aplicativo DMV e abra novamente. Se ainda aparecer a versao antiga, abra o link no Chrome/Safari e atualize a pagina.

O botao aparece apenas se o perfil ativo retornado por public.perfis tiver papel = administrador.
No celular, ele aparece tambem ao abrir uma OS em Ver OS, no bloco vermelho Ação do administrador > Excluir esta OS. Na tabela, pode ser necessario deslizar a tabela para a direita ate a coluna Acoes.

A funcao SQL dmv_excluir_ordem_servico(uuid) precisa estar criada no Supabase. Esta atualizacao nao modifica os dados nem cria a funcao SQL.
